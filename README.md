# Skycast

Weather app with animated backgrounds (sunny day, clear night, clouds, rain, snow, hail, thunderstorm),
24-hour and 7-day forecast, live rain radar map, air quality (US AQI), and °C/°F toggle, and light/dark/auto theme.
Plain HTML, CSS and JavaScript. No API keys.

## Files
- `index.html` – page
- `style.css` – styles
- `effects.js` – canvas weather animations
- `app.js` – data, radar map, air quality

## Run
Open `index.html`, or run `npx serve .`

## Deploy
Repo → Settings → Pages → Deploy from branch → `main` / root.

## Data sources
Open-Meteo (weather, air quality), RainViewer (radar), OpenStreetMap (map), Leaflet.
